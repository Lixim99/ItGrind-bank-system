# Банковская система

Учебный объектно-ориентированный проект по ТЗ ItGrind «База ООП». Система
моделирует банковские счета, клиентов, транзакции, очередь операций,
риск-анализ, аудит и экспорт аналитических отчётов.

## Возможности

- обычные, сберегательные, премиальные и инвестиционные счета;
- статусы счетов, лимиты, комиссии, минимальный остаток и овердрафт;
- регистрация и аутентификация клиентов с блокировкой после трёх ошибок;
- приоритетные и отложенные транзакции, отмена и повторные попытки;
- мультивалютные переводы и комиссия за внешние операции;
- блокировка ночных и высокорисковых операций;
- аудит в памяти и JSON Lines-файле;
- отчёты по клиенту, банку, транзакциям и рискам в TXT, JSON и CSV;
- круговая и столбчатая диаграммы, график движения баланса;
- демонстрационный сценарий из 5 клиентов, 10 счетов и 30 транзакций.

Описание взаимодействия компонентов находится в
[`docs/algorithm.md`](docs/algorithm.md).

## Запуск локально

Требуется Python 3.13 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.main
```

Демонстрация сохраняет аудит, отчёты и PNG-графики в `public/uploads/`.

## Тесты

```bash
python -m pytest -q
```

Тесты сгруппированы по модулям и проверяют требования всех семи дней,
включая полный интеграционный сценарий.

## Запуск в Docker

Для запуска только демонстрационного приложения достаточно:

```bash
docker build -t bank-system .
docker run --rm -v "$(pwd)/public/uploads:/app/public/uploads" bank-system
```

`compose.yaml` дополнительно запускает PostgreSQL как заготовку для будущего
слоя хранения. Перед `docker compose up --build` скопируйте `.env.example` в
`.env`.
